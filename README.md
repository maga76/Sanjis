# Sanjish (Санҷиш)

Android-приложение для подготовки к школьным тестам (Таджикистан, 1–11 класс).
Flutter, языки — таджикский (по умолчанию) и русский. Работает без интернета.

## Что умеет

**Ученик**
- Регистрация и вход по почте и паролю, восстановление пароля, вход через Google
  (когда подключён Firebase — [docs/GOOGLE_SIGN_IN.md](docs/GOOGLE_SIGN_IN.md)).
- 15 предметов → класс → темы → тест. Правильный ответ зелёный, неправильный красный,
  объяснение. Вопросы и варианты перемешиваются. Результат: процент и оценка 2–5.
- Работа над ошибками: список ошибок и тест по ним.
- Профиль: статистика, последние результаты, редактирование данных.
- Настройки: язык, тема (светлая/тёмная), крупный шрифт.

**Админ**
- Вопросы: просмотр, добавление, изменение, удаление (тадж./рус., 2–6 вариантов, объяснение).
- Предметы: добавление, переименование и удаление тем, классы темы.
- Статистика: ученики, тесты, средний результат, ученики по классам и регионам,
  самые сложные вопросы.

## Где хранятся данные

**С Firebase** (есть `android/app/google-services.json`) — онлайн, в проекте Firebase:
аккаунты (почта/пароль и Google), темы и вопросы админа, результаты учеников.
Правки админа сразу видят все ученики; без интернета приложение работает и
досылает данные позже. Правила доступа — [firestore.rules](firestore.rules)
(вставляются в Firebase Console → Firestore Database → Rules).
Админ — почта из `kAdminEmails` в `lib/features/auth/application/auth_service.dart`
(вход через Google).

**Без Firebase** — всё на телефоне; админ по умолчанию `admin@sanjish.tj` / `admin123`.

В приложении 300 демо-вопросов (по 10 в 30 темах).

## Установка и запуск

Пошаговая инструкция для Windows: [docs/INSTALL_WINDOWS.md](docs/INSTALL_WINDOWS.md).

Коротко (после установки Flutter):

```powershell
cd C:\projects\sanjish
flutter create . --org tj --project-name sanjish --platforms android   # один раз: создаёт android/
flutter pub get
flutter analyze
flutter test
flutter run
```

## Структура

```
lib/
  main.dart
  app/        роутер, тема, настройки (язык/тема/шрифт)
  core/       локализация, константы, утилиты, общие виджеты
  l10n/       app_tg.arb (шаблон), app_ru.arb; generated/ — создаётся автоматически
  features/
    onboarding/  заставка, выбор языка
    auth/        вход, регистрация
    student/     главная, ошибки, профиль
    admin/       вопросы, предметы, статистика
    settings/    настройки
```

## Важные заметки

- **Таджикская локаль.** Во Flutter нет системных (Material) переводов для `tg`.
  В `lib/core/l10n/tg_fallback_localizations.dart` для `tg` подставляются русские
  системные строки (кнопки диалогов, календарь), а тексты приложения берутся из `app_tg.arb`.
  Даты форматируются вручную (`lib/core/utils/date_formatter.dart`), т.к. `intl` не знает `tg`.
- **Тексты на таджикском должен проверить носитель языка** — файл `lib/l10n/app_tg.arb`.
- **Шрифт** Noto Sans подключён файлами из `assets/fonts/` (лицензия SIL OFL), в нём есть все
  таджикские буквы: Ғ ғ, Ӣ ӣ, Қ қ, Ӯ ӯ, Ҳ ҳ, Ҷ ҷ.
- **Клавиатура админа.** Для ввода ҳ, ҷ, ӣ, ӯ, қ, ғ установите Gboard и добавьте
  язык «Тоҷикӣ» (Настройки Gboard → Языки → Добавить клавиатуру).
- **Путь проекта** должен быть без кириллицы и пробелов — иначе сборка Android на Windows падает.
